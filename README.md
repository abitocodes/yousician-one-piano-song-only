# 🎹 피아노 노래방

**진짜 피아노로 치면, 태블릿 마이크가 듣고 판정하는 노래방 스타일 리듬게임**

화면 위에서 노트가 떨어지고, 판정선에 닿는 순간 실제 피아노(어쿠스틱·디지털 모두 가능)의 건반을 누르면
태블릿 마이크가 **음정과 타이밍**을 분석해 PERFECT / GREAT / GOOD / MISS 를 매깁니다.
노래방 기계처럼 **가사의 색이 부르는 위치를 따라 차오르기** 때문에, 치면서 함께 노래할 수 있어요.

- 🎤 마이크 음높이·온셋 분석 (설치 없이 브라우저에서 실시간 처리)
- 🎼 위에서 떨어지는 노트 + 화면 아래 피아노 건반 (도레미 / C4 표기)
- 🎶 노래방식 가사 색 채우기 (두 줄 번갈아 표시, 전주 카운트 점)
- 🧭 연습 모드: 맞는 건반을 칠 때까지 기다려 주는 "웨이트 모드"
- 📱 삼성 갤럭시 탭 최적화 (가로·세로, 전체화면, 홈 화면 앱 설치, 오프라인 사용)

> **바로 실행:** https://abitocodes.github.io/yousician-one-piano-song-only/

## 갤럭시 탭에서 사용하기

1. **브라우저로 열기** — 갤럭시 탭의 **Chrome** 또는 **삼성 인터넷**에서 위 주소를 엽니다.
   마이크는 보안 연결(HTTPS)에서만 동작하므로 반드시 `https://` 주소로 접속하세요.
2. **홈 화면에 추가** — Chrome: 메뉴(⋮) → **홈 화면에 추가** / 삼성 인터넷: 메뉴(≡) → **현재 페이지 추가 → 홈 화면**.
   홈 화면 아이콘으로 실행하면 주소창 없이 전체화면 앱처럼 동작하고, 한 번 연 뒤에는 오프라인에서도 쓸 수 있어요.
3. **마이크 허용** — 처음 **시작**을 누르면 마이크 권한을 묻습니다. **허용**을 눌러 주세요.
   실수로 거부했다면 주소창의 자물쇠(사이트 설정) → 권한 → 마이크를 허용한 뒤 새로고침하세요.
4. **가로 모드 추천** — 태블릿을 피아노 보면대에 가로로 세워 두세요. 홈 화면의 **전체화면** 버튼을 누르면 가로로 고정을 시도해요.
   세로 모드에서도 플레이할 수 있어요.
5. **처음 한 번 보정하기** — 홈의 **마이크·보정** 화면에서
   - 피아노를 쳐 보며 소리 크기 막대와 감지된 음 이름이 반응하는지 확인하고, 필요하면 **감도**를 조절해요.
   - **자동 측정**을 누르고, 노트가 판정선에 닿을 때마다 아무 건반이나 한 번씩 치면 마이크 지연(레이턴시)이 자동으로 맞춰져요.
   - 피아노 조율이 표준(A4 = 440Hz)과 다르면 **기준음**을 맞춰 주세요.

> 💡 마이크가 피아노 쪽을 향하도록 두고, 가이드 멜로디·반주를 함께 쓸 때는 **이어폰**을 쓰면 판정이 훨씬 정확해요.

## "감사" 악보 직접 만들기

저작권 때문에 김동률 「감사」의 멜로디와 가사는 앱에 들어 있지 않아요(아래 [저작권 안내](#저작권-안내) 참고).
대신 홈 화면의 **감사** 카드가 빈 템플릿으로 준비되어 있어서, **악보 만들기**를 누르면 편집 화면에서 직접 채울 수 있어요.
저장하면 템플릿 자리에 내 악보가 들어가고 바로 플레이할 수 있습니다.
아래 방법은 서로 섞어 써도 돼요(예: MIDI로 가져온 뒤 가사만 붙여넣기).

### 1) MIDI 가져오기

직접 구입했거나 직접 만든 MIDI 파일(`.mid`)이 있다면 가장 빠른 방법이에요.

1. 편집 화면 → **멜로디 노트** → **MIDI 가져오기** → 파일 선택
2. 트랙 목록(이름 · 노트 수 · 음역 · 채널 · 드럼 여부)에서 **멜로디 트랙**을 고릅니다.
3. 옵션
   - **멜로디만 추출**(기본 켜짐): 화음이 있으면 가장 높은 음만 남겨 한 줄 멜로디로 만들어요.
   - **이조**: −12 ~ +12 반음. 내 피아노·목소리에 맞게 조를 바꿔요.
   - **BPM·박자도 가져오기**: MIDI의 템포와 박자표를 곡 정보에 반영해요.
4. **적용** 후, 노트 도구(반음 ±, 옥타브 ±, 시간 ±0.05초, 앞 공백 제거)로 다듬습니다.

### 2) 피아노로 녹음

MIDI가 없다면 **피아노로 직접 쳐서** 악보를 받아 적을 수 있어요.

1. 편집 화면에서 **BPM**을 먼저 맞추고 **피아노로 녹음**을 누릅니다(마이크 권한 필요).
2. 4번의 카운트인 뒤에 멜로디를 한 음씩 또렷하게 칩니다. 감지된 음이 실시간 목록에 나타나요.
   - 녹음 중 메트로놈을 켤 수 있지만, 클릭 소리가 음으로 잡힐 수 있으니 이어폰을 추천해요.
3. **정지** 후 박자 정리(퀀타이즈: 끄기 / 8분 / 16분)를 고르고 **교체** 또는 **뒤에 추가**합니다.
4. 한 번에 다 치기 어렵다면 소절별로 나눠 녹음하고 **뒤에 추가**로 이어 붙이세요.

### 3) 텍스트로 입력

음 이름과 박자를 글자로 적어서 만들 수도 있어요. 편집 화면 → **텍스트로 입력**.

```
# 주석은 #으로 시작해요
C4 D4 E4:2 | 도4 레4 미4:2 | R:1
F#3:1/2 Bb4:1.5 솔#:0.5 쉼:2
```

| 쓰는 법 | 뜻 |
| --- | --- |
| `C4`, `F#3`, `Bb4` | 영문 음 이름 + 옥타브 (가운데 도 = `C4`) |
| `도4`, `솔#3`, `시` | 계이름도 가능. 옥타브를 생략하면 4옥타브 |
| `:2`, `:0.5`, `:1/2` | 박자 수 (생략하면 1박) |
| `R`, `쉼`, `rest` | 쉼표 (`R:2` = 2박 쉼) |
| `|`, `,`, 줄바꿈 | 보기 좋게 나누는 구분자 (소리에는 영향 없음) |

**현재 노트를 텍스트로** 버튼으로 지금 노트를 텍스트로 꺼내 고칠 수도 있어요.

### 4) 가사 붙여넣기와 문법

편집 화면 → **가사** 칸에 가사를 붙여넣고 **노트에 자동 배치**를 누르면, 글자가 노트에 하나씩 순서대로 붙어
노래방처럼 색이 차오릅니다.

- **한 줄 = 화면에 함께 보이는 한 소절.** 빈 줄, `#`으로 시작하는 줄, `[1절]` 같은 구간 표시는 무시돼요.
- **한글 한 글자 = 노트 하나.** 영어는 띄어쓰기로 나뉜 단어 하나가 노트 하나이고, `twin-kle`처럼 `-`로 음절을 나눌 수 있어요.
- `~` : 앞 글자를 다음 노트까지 늘려요(한 글자를 여러 음으로 부를 때). 예: `사~랑해`
- `_` : 가사 없이 노트 하나를 건너뛰어요(간주·꾸밈음). 예: `_ 하나`
- 문장부호(`, . ! ?` 등)는 앞 글자에 붙어서 표시돼요.
- 글자 수와 노트 수가 다르면 "가사 음절이 노트보다 N개 많아요" 같은 안내가 나와요. `~`, `_`로 맞춰 주세요.
- **계이름으로 채우기**: 가사 대신 "도 레 미…"를 자동으로 채워서 계이름을 부르며 연습할 수 있어요.

### 5) LRC 가사 파일

이미 시간이 맞춰진 **LRC** 가사 파일(`[00:12.34]가사…`, 단어별 `<00:12.80>` 형식 포함)이 있다면
**LRC 가져오기**로 노트와 별개로 가사 타이밍을 그대로 쓸 수 있어요. 반대로 **LRC 내보내기**로 내 가사 타이밍을 저장할 수도 있습니다.

### 6) 반주 음원 (선택)

직접 가지고 있는 음원 파일을 **반주 음원**으로 지정하면 연주에 맞춰 함께 재생돼요(시작 위치·음량 조절 가능).
반주를 틀고 마이크로 판정할 때는 **이어폰**을 꼭 써 주세요. 음원은 이 기기에만 저장되고 곡 파일(.json)에는 포함되지 않아요.

### 백업과 다른 기기로 옮기기

편집 화면의 **내보내기 (.json)** 또는 설정 → **모든 내 곡 내보내기**로 곡 파일을 저장하고,
다른 기기에서 홈의 **곡 파일 가져오기(.json)**로 불러오면 됩니다.

## 모드 설명

| 모드 | 설명 |
| --- | --- |
| ▶ **플레이** | 실제 판정 모드. 점수(최대 1,000,000점)·콤보·정확도를 기록하고, 최고 기록은 곡 카드에 표시돼요. |
| **연습** (웨이트 모드) | 노트가 판정선에 오면 **맞는 건반을 칠 때까지 멈춰서 기다려요.** 틀려도 MISS가 없어요. 연습 기록은 최고점에 반영되지 않아요. |
| **듣기** | 가이드 멜로디가 자동으로 연주되고 가사가 흘러가요. 곡을 익히거나 악보가 맞는지 확인할 때 써요. |

판정 등급은 타이밍 차이로 정해져요 (난이도 "보통" 기준: PERFECT ±70ms · GREAT ±140ms · GOOD ±230ms).
**입력 방식**은 홈 상단의 칩을 눌러 바꿀 수 있어요.

- 🎤 **마이크**: 실제 피아노 소리로 판정 (기본)
- 👆 **터치**: 화면 건반을 직접 눌러서 플레이 (마이크 없이)
- 🤖 **시뮬레이션**: 자동 연주 소리를 판정기에 넣어 동작을 확인하는 테스트 모드

## 설정과 문제 해결

설정 화면에서 바꿀 수 있는 것: 입력 방식, 마이크 감도, 입력 지연 보정, 기준음(A4), 옥타브 무시, 감지된 음 표시,
난이도, 재생 속도(50~125%), 노트가 보이는 시간, 노트 이름(도레미/C4/없음), 가사 표시, 가이드 멜로디, 메트로놈,
화면 켜짐 유지, 전체 음량, 반주 음량.

### 판정이 잘 안 될 때

- **소리가 감지되지 않아요** → 설정의 **마이크 감도**를 올리세요. 보정 화면의 소리 막대가 피아노를 칠 때 움직이는지 확인해요.
  태블릿 케이스가 마이크 구멍을 가리지 않는지도 확인하세요.
- **엉뚱한 음이나 주변 소리가 판정돼요** → 감도를 낮추세요. 가이드 멜로디·메트로놈·반주는 **이어폰**으로 들어야 마이크가 그 소리를 듣지 않아요.
- **항상 늦게(또는 빠르게) 판정돼요** → 보정 화면에서 **자동 측정**을 다시 하세요. 결과 화면의 "평균 N ms 늦음"이 0에 가까워지면 잘 맞은 거예요.
- **음은 맞게 쳤는데 MISS가 나요** → 피아노 소리의 배음 때문에 마이크가 옥타브를 헷갈릴 수 있어요. **옥타브 무시**를 켜 두세요(기본 켜짐).
  조율이 표준과 다른 피아노라면 **기준음(A4)**도 맞춰 주세요.
- **너무 빨라요** → **재생 속도**를 70~80%로 낮추거나 **연습** 모드로 먼저 익혀 보세요.

### 그 밖의 문제

- **마이크 권한을 거부했어요** → 주소창 자물쇠(사이트 설정) → 권한 → 마이크 허용 → 새로고침.
- **"HTTPS 주소에서만 사용할 수 있어요"가 떠요** → `https://` 주소로 접속하세요. (로컬 개발 시에는 `http://localhost` 도 허용돼요)
- **업데이트가 반영되지 않아요** → 앱은 오프라인용으로 파일을 저장해 두고 백그라운드에서 갱신해요. 한 번 더 새로고침하거나,
  설정 → 문제 해결 → **앱 새로 고침 (캐시 삭제)**을 누르세요.
- **화면이 꺼져요** → 설정의 **화면 켜짐 유지**를 켜세요(플레이 중에만 동작).

## 저작권 안내

김동률 「감사」의 **멜로디(악보)와 가사는 저작권으로 보호되는 저작물**이라 이 저장소와 앱에 포함하지 않았어요.
앱에는 빈 템플릿만 들어 있고, 사용자가 **직접 소유한 자료**(구입한 악보·MIDI, 직접 연주한 녹음 등)로 개인적인 연습용 악보를 만들 수 있는
도구(MIDI 가져오기, 피아노로 녹음, 텍스트 입력, 가사 붙여넣기)를 제공합니다.
사용자가 만든 곡은 사용자의 기기(브라우저 저장소)에만 저장되며, 서버로 전송되지 않아요.
만든 악보·가사를 다른 사람에게 배포하거나 공개하는 것은 저작권 침해가 될 수 있으니 개인 연습 용도로만 사용해 주세요.

기본으로 들어 있는 곡은 다음 두 곡뿐이에요.

- **건반 위의 산책** — 이 프로젝트를 위해 새로 만든 오리지널 연습곡(멜로디·가사)
- **작은 별 (계이름 노래)** — 저작권이 만료된 프랑스 민요 선율에 계이름(도레미)을 붙인 연습곡

# 정적 서버 실행 (아무 정적 서버나 가능)

| 옵션 | 효과 |
| --- | --- |
| `?input=sim` | 이번 세션만 시뮬레이션 입력(자동 연주 → 판정기)으로 실행. 마이크 없이 전체 파이프라인 확인 |
| `?input=touch` / `?input=mic` | 이번 세션만 터치 / 마이크 입력 |
| `?nosw` | 서비스 워커를 등록하지 않고, 기존 등록도 해제 (개발 중 캐시 문제 방지) |
| `?screen=settings` | 시작하자마자 설정(또는 `calibrate`, `editor`) 화면 열기 |

- 데스크톱에서 테스트할 때는 키보드 `a w s e d f t g y h u j k` 가 C4~C5 건반, `Space` 가 일시정지예요.
- 아이콘은 `node tools/make-icons.mjs` 로 다시 만들 수 있어요(외부 의존성 없음).
- GitHub Pages 배포: 저장소 Settings → Pages → 브랜치 루트(`/`)를 선택하면 끝. 모든 경로가 상대 경로라 하위 경로에서도 동작해요.
